# Доступ разработчика: регистрация и заявка

## Что происходит на самом деле

Публичная точка входа — [Request access to Poki for Developers](https://developers.poki.com/guide/share). Маршрут разделяет `Request access` и `Sign In`; Poki просит рассказать о себе и обещает связаться, чтобы предоставить доступ. Poki не раскрывает, полностью ли решение принимается вручную и как именно активируется доступ.

Poki не публикует:

- отдельный проходной балл для студии или разработчика;
- обязательное число ранее выпущенных игр;
- минимальный размер команды/выручку/юридическую форму;
- гарантированный срок ответа на заявку;
- обещание доступа каждому заполнившему форму.

Не стоит придумывать эти критерии или выдавать советы из форумов за правила Poki.

После предоставления доступа Terms допускают создание аккаунта через сторонний сервис, например Discord, GitHub или Google; данные должны оставаться правдивыми, полными и актуальными ([Terms of use P4D](https://app.poki.dev/2024.03.13_Terms_and_Conditions_Poki_for_Developers.pdf)).

## Поля актуальной формы

Поля проверены непосредственно в форме 9 сентября 2026 года.

| Поле | Обязательное | Что доступно в форме |
|---|---:|---|
| Name | да | имя контактного лица |
| Email | да | рабочий email |
| Studio or team name | да | название команды/студии |
| Country | да | страна нахождения |
| Studio/team description | да | AAA Studio; AA / Mid-Sized Studio; Indie Studio; Solo Developer; Outsourcing / Co-Development Studio; Tools / Technology Provider; Publisher; Educational / Student Team |
| Previously released platforms | нет — поле не помечено Required | Consoles; Mobile App Stores; Web; Steam / PC; Roblox; VR |
| Links to games | да | игры, портфолио и другие проверяемые ссылки |
| Genres | да | свободный текст |
| Engines | да | свободный текст |
| Goals with Poki | да | Releasing existing titles; Releasing new titles; Using our developer tools |

Источник: [официальная форма](https://developers.poki.com/guide/share). В форме можно выбрать несколько вариантов в трёх списках.

## Как заполнить сильную заявку

Это рекомендации, основанные на обязательных полях формы и опубликованных критериях Poki ([что ищет Poki](https://developers.poki.com/guide/what-we-look-for)); Poki не называет их гарантией доступа.

### Контакт и идентичность

- Использовать имя реального ответственного человека и адрес `hello@serendipity-games.com` либо персональный рабочий адрес, который регулярно читается.
- Название писать единообразно: **Serendipity Games**.
- Выбрать честный тип: вероятнее всего **Indie Studio**; если игру делает один человек — также/вместо этого **Solo Developer**. Не увеличивать размер команды на словах.
- Указать реальную страну физлица или юрлица. Poki говорит, что team/contact/country data будут использованы, если игра пройдёт тесты, но не уточняет публично конкретную договорную или платёжную функцию каждого поля ([P4D platform](https://developers.poki.com/guide/p4d-platform)).

### Доказательства

- Первой ссылкой дать студийный сайт: `https://serendipity-games.com/`.
- Второй — прямой URL одной лучшей игры, которая открывается без логина и скачивания.
- Добавить 1–2 следующих демо только если они не снижают общее впечатление.
- Если есть реальные страницы релизов, профили магазинов или публичная аналитика — указать их. Не называть портфолио-релизы «выпущенными на платформе», если это демо.
- Одним предложением отметить собственность/лицензии на код, арт, музыку и название. Подробные доказательства держать готовыми, но не перегружать поле ссылок.

### Позиционирование

- Жанры назвать узко и честно: например `casual action, arcade puzzle, runner, match puzzle`.
- Движки перечислить фактически используемые, например `HTML5 / JavaScript / TypeScript, Three.js` — после сверки с исходными проектами.
- Для целей отметить `Releasing existing titles`, `Releasing new titles` и `Using our developer tools`, если все три соответствуют плану.
- В свободном контексте (если Poki запросит дополнение) сформулировать web-first тезис: быстрый вход, mobile + desktop, короткие повторяемые циклы, план обновлений.

## Что Poki, вероятно, оценивает уже на входе

**Факт:** публичные критерии игр — quality/UX и core loop, player fit, техническая состоятельность, оригинальность, глубина, первое впечатление, работа на разных устройствах и возможность развивать игру ([What we look for](https://developers.poki.com/guide/what-we-look-for)).

**Вывод:** поскольку форма требует ссылки на игры, жанры, движки и цель сотрудничества, заявку разумно строить как быстро проверяемое доказательство именно этих качеств. Это не подтверждает, что Poki формально выставляет студии те же оценки.

## Что происходит после доступа

- В P4D создаётся команда; можно добавить пользователей с ролями `Developer` и `Developer Support`. Вторая роль имеет ограниченный доступ к earnings и monetization metrics после релиза ([P4D platform](https://developers.poki.com/guide/p4d-platform)).
- Billing появляется как практический шаг, если игра пройдёт тесты и выйдет.
- Загрузка прототипа разрешена, но каждая новая версия до QA/Soft/Global Release проходит модерацию контента ([Adding your game](https://developers.poki.com/guide/adding-your-game)).

## Если ответа на заявку нет

Публичного срока и процедуры апелляции нет. Анонимные форумные сообщения о сроках ненадёжны и относятся к меняющимся версиям процесса. Практически разумно не создавать серию дубликатов, а через 2–3 недели отправить один короткий follow-up с датой заявки, названием студии и ссылкой на flagship. `developersupport@poki.com` официально указан для поддержки аккаунта/SDK, но Poki не называет его отдельным каналом апелляции по заявке; поэтому это рекомендация, а не обещанный процесс.

## Перед нажатием Submit

- [ ] Все сведения правдивы, актуальны и одинаковы на сайте/в email/в форме.
- [ ] Первая ссылка работает без авторизации на телефоне и компьютере.
- [ ] На сайте ясно написано, кто студия, какие игры делает и как связаться.
- [ ] Лучшее демо открывается быстро и не показывает чужой SDK/бренд/магазин.
- [ ] Права на код, визуалы, звук, шрифты и название документированы.
- [ ] Англоязычный pitch проверен человеком.
- [ ] Личные поля и страна заполнены владельцем аккаунта, без выдуманных данных.
