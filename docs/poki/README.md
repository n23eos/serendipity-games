# Poki: база знаний для разработчика

Актуальность проверки: **9 сентября 2026 года**. Основной источник — текущая официальная документация Poki for Developers. Условия договора и метрики могут меняться, поэтому перед фактической подачей нужно пройти короткую перепроверку по ссылкам.

## Главный вывод

У Poki два разных решения, которые нельзя смешивать:

1. **Доступ разработчика.** Сначала подаётся заявка на доступ к Poki for Developers. Это не обычная мгновенная регистрация: Poki просит сведения о команде, ссылки на выпущенные игры/портфолио, жанры, движки и цели сотрудничества, после чего обещает связаться с заявителем. Публичной формулы оценки разработчика и публичного SLA ответа Poki не публикует ([форма заявки](https://developers.poki.com/guide/share)).
2. **Одобрение конкретной игры.** Получение аккаунта не означает публикацию. Игра проходит модерацию контента, playtest, Player Fit Test, Web Fit Test и Final Review; только затем обсуждаются договор, QA, Soft Release и Global Release ([процесс тестирования](https://developers.poki.com/guide/how-testing-works), [условия P4D](https://app.poki.dev/2024.03.13_Terms_and_Conditions_Poki_for_Developers.pdf)).

Лучший способ повысить шанс на доступ — не писать общую историю про «мечту делать игры», а показать проверяемый профиль web-first студии: живой сайт, 1–2 сильных мгновенно запускаемых демо, права на весь контент, конкретный жанровый фокус, техническая готовность к mobile web и понятная цель работы с Poki. Это **рекомендация по совокупности полей формы и критериев Poki**, а не опубликованный Poki балльный порог.

## Короткий маршрут действий

1. Выбрать **одну флагманскую игру**, а не отправлять четыре неодинаково готовых билда.
2. Сделать отдельный Poki-build: проверенная локализация и предпочтительно автоопределение языка браузера (English-first — проектное решение для первой подачи), Poki SDK, без чужих SDK и покупок, без неразрешённых сетевых запросов.
3. Добиться малого первого скачивания, быстрого первого действия и стабильной работы на телефоне, планшете и компьютере.
4. Подготовить честную квадратную обложку и короткий pitch; проверить билд в Poki Inspector.
5. Подать заявку на доступ через [официальную форму](https://developers.poki.com/guide/share), указав сайт `https://serendipity-games.com/` и прямую ссылку на лучший демо-билд.
6. После доступа использовать бесплатные тесты итеративно; не просить Final Review на минимальном проходном результате.

Целевые ориентиры перед Final Review: **65%+ conversion-to-play**, **5+ минут среднего playtime** (для management/simulation — **10+ минут**). Средняя игра Poki находится примерно на 70% C2P и 6+ минутах; Poki прямо советует считать эти значения полом, а не финишем ([официальный обзор тестов](https://developers.poki.com/guide/how-testing-works)).
